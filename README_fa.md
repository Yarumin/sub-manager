<h1 align="center">Sub Manager</h1>

<p align="center">پنلی برای مدیریت سابسکریپشن‌ها و کانفیگ‌های پروکسی روی Cloudflare Workers</p>

<br>

ساب منیجر سابسکریپشن‌ها و کانفیگ‌های دستی (VLESS، Trojan، Shadowsocks، VMess) را در یک لینک خروجی واحد ادغام می‌کند و در این مسیر روی هر کانفیگ پردازش‌هایی مثل جایگزینی آی‌پی تمیز، فیلتر پورت، و تنظیمات TLS اعمال می‌کند. کل پروژه به‌صورت یک Cloudflare Worker با یک KV namespace برای ذخیره‌سازی اجرا می‌شود.

## ویژگی‌ها

- ادغام چند لینک سابسکریپشن و کانفیگ‌های دستی در یک خروجی واحد.
- جایگزینی آدرس هر کانفیگ با یک آی‌پی تمیز از یک لیست مدیریت‌شده، به‌صورت ضرب در همه‌ی آی‌پی‌های لیست یا انتخاب تصادفی یکی از آن‌ها برای هر کانفیگ.
- تنظیمات جداگانه برای هر منبع و هر لینک: لیست آی‌پی تمیز، فیلتر پورت، یک کانفیگ برای هر پورت، محدود کردن جایگزینی به رنج‌های شناخته‌شده‌ی کلودفلر.
- به‌روزرسانی خودکار هر منبع لینکی با بازه‌ی زمانی خودش، در اولین درخواست بعد از موعد مقرر — بدون نیاز به Cron Trigger.
- خروجی و ورودی گرفتن از منابع، لیست‌های آی‌پی تمیز، و اتصالات کلودفلر به‌صورت یک فایل JSON، با حالت ترکیب یا جایگزینی.
- نمایش تعداد درخواست‌های روزانه‌ی Worker در پنل، در صورت اتصال یک توکن API کلودفلر.
- رفع محدودیت آپلود: تنظیم فینگرپرینت TLS و cipher suites روی کانفیگ‌های VLESS و Trojan، با روشی که [Patterniha](https://github.com/patterniha) در [پول‌ریکوئست #5900](https://github.com/2dust/v2rayNG/pull/5900) به v2rayNG اضافه کرده است.
- تغییر نام، جابه‌جایی، و غیرفعال‌سازی موقت هر کانفیگ بدون حذف آن.

## محدودیت‌ها

- این پنل خودش پروکسی نیست — Worker ترافیک VLESS/Trojan/Shadowsocks را پردازش نمی‌کند، فقط کانفیگ‌هایی را که به یک مقصد فعال اشاره می‌کنند ذخیره، ادغام و بازنشر می‌کند.
- پلن رایگان کلودفلر روزانه ۱۰۰ هزار خواندن و ۱۰۰۰ نوشتن روی KV می‌دهد که بین کل Worker مشترک است. برای استفاده‌ی شخصی کافی است.
- هر بخش حداکثر ۱۰۰۰ کانفیگ پایه نگه می‌دارد؛ بعد از ضرب در تعداد آی‌پی‌های تمیز، خروجی هر بخش حداکثر ۶۰۰۰ خط است و مازاد بر آن به‌صورت تصادفی نمونه‌برداری می‌شود.
- واکشی لینک سابسکریپشن بعد از ۱۵ ثانیه timeout می‌شود؛ منابع غیرقابل‌دسترس به‌عنوان ناموفق علامت می‌خورند.

## راه‌اندازی

فقط به یک اکانت رایگان کلودفلر نیاز است.

یک ورکر جدید بسازید و فایل `worker.js` را از بخش [Releases](https://github.com/Yarumin/sub-manager/releases) دانلود و روی همان ورکر دیپلوی کنید.

از بخش **Storage & Databases** و سپس **Workers KV** یک KV namespace با نام دلخواه بسازید.

در تنظیمات ورکر، به بخش **Bindings** بروید و یک KV binding دقیقاً با نام `SUB_DB` به namespace‌ای که در مرحله‌ی قبل ساخته بودید متصل کنید. سپس به عقب برگردید و از بخش **Settings** و بعد **Variables and Secrets**، یک Secret با نام `ADMIN_PASSWORD` و یک رمز دلخواه اضافه و دیپلوی کنید. بدون انجام این مرحله، پنل با رمز پیش‌فرض `admin123` کار می‌کند و تا تنظیم یک رمز واقعی، یک هشدار نمایش می‌دهد. (اگر رمز کار نکرد، Compatibility Date ورکر را به `2026-08-04` تغییر دهید.)

با قرار دادن عبارت `/app` در انتهای لینک ورکر به پنل دسترسی خواهید داشت (`https://<worker-name>.<subdomain>.workers.dev/app`).

تنظیم Cron Trigger اختیاری است. بدون آن، هر درخواست کلاینت همیشه همان خروجی کش‌شده‌ی قبلی را می‌گیرد و اگر منبعی از موعدش گذشته باشد، رفرش آن فقط بعد از همان درخواست و در پس‌زمینه انجام می‌شود؛ یعنی نتیجه‌ی به‌روزشده در درخواست بعدی دیده می‌شود. با تنظیم Cron Trigger، منابع با بازه‌ی زمانی خودشان در پس‌زمینه رفرش می‌شوند، پس احتمال بیشتری هست که خروجی کش‌شده از قبل به‌روز باشد وقتی کلاینت درخواست می‌زند. این تنظیم از بخش **Settings** و سپس **Triggers** قابل افزودن است، برای مثال با الگوی `0 * * * *` برای هر ساعت یک‌بار.

برای به‌روزرسانی به نسخه‌ی جدید، کافی است مرحله‌ی دیپلوی را با `worker.js` جدید تکرار کنید؛ داده‌های ذخیره‌شده در KV تغییری نمی‌کنند.

## اجرا از روی سورس

برای اکثر کاربران، دانلود `worker.js` از بخش Releases کافی است. برای ساخت محلی یا دیپلوی مستقیم با Wrangler، به [Node.js](https://nodejs.org) نیاز دارید. ابتدا سورس را کلون و پکیج‌ها را نصب کنید:

```bash
git clone https://github.com/Yarumin/sub-manager.git
cd sub-manager
npm install
```

برای ساخت یک فایل `worker.js` تکی (خروجی‌ای یکسان با فایل Releases)، دستور زیر را اجرا کنید:

```bash
npm run build
```

فایل نهایی در `dist/worker.js` ساخته می‌شود؛ همین فایل را مثل بخش راه‌اندازی روی ورکر دیپلوی کنید.

برای دیپلوی مستقیم از روی سورس با Wrangler، ابتدا وارد شوید:

```bash
npx wrangler login
```

مقدار `REPLACE_WITH_YOUR_KV_NAMESPACE_ID` را در فایل `wrangler.jsonc` با آیدی KV namespace‌ای که ساختید جایگزین کنید (این آیدی از بخش Storage & Databases و سپس Workers KV در داشبورد کلودفلر قابل مشاهده است)، سپس دستورهای زیر را اجرا کنید:

```bash
npx wrangler deploy
npx wrangler secret put ADMIN_PASSWORD
```

## ساختار کد

```
src/
  index.js          نقطه‌ی ورود (fetch / scheduled)
  constants.js
  utils/             توابع کمکی بدون وضعیت
  authz/             سشن، بررسی رمز عبور، محدودسازی نرخ ورود
  configEngine/      پارس کانفیگ، اثرانگشت‌گیری، تولید خروجی
  storage/           خواندن و نوشتن روی KV، خروجی و ورودی بک‌آپ
  sync/              واکشی سابسکریپشن، به‌روزرسانی خودکار
  api/               هندلرهای مسیر /api/*
  publicApi/         مسیر عمومی /sub/{slug}
  panel/             HTML پنل ادمین و اسکریپت سمت کلاینت
scripts/
  build.mjs          باندل کردن src/ به dist/worker.js
```
